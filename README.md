# 坦克大战 Tank Battle

一个纯 HTML5 + Canvas + JavaScript 实现的经典坦克大战游戏，无需任何依赖，单文件即可运行。

## 玩法

- **目标**：消灭所有敌方坦克，保护地图底部的金色基地。基地被毁或生命耗尽即失败。
- 每关敌人数量递增、速度变快，通关自动进入下一关（共 3 张地图循环）。

### 操作

| 按键 | 功能 |
|------|------|
| 方向键 / W A S D | 移动 |
| 空格 / J | 射击 |
| P | 暂停 |
| M | 静音 |

### 地形

- 🟫 **砖墙**：可被子弹击破
- ⬜ **钢墙**：普通子弹无法击破（火力升级后可以）
- 🌊 **水**：阻挡坦克，不阻挡子弹
- 🌿 **草丛**：隐藏坦克

### 道具（击毁敌人随机掉落）

- ★ **火力升级**：双发 → 可破钢墙
- ❤ **额外生命**
- ❄ **冻结敌人**
- ✹ **全屏轰炸**

## 运行

直接用浏览器打开 `index.html` 即可，或启动本地服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 技术说明

- 单文件、零依赖，所有音效由 Web Audio API 实时合成
- 敌人 AI：随机移动 + 卡墙自动转向 + 概率开火
